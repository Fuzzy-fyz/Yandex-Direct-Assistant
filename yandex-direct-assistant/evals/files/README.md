# Тестовые выгрузки

Все файлы в этой папке **синтетические**: они сгенерированы для проверки навыка и не являются выгрузками реального рекламного кабинета, Метрики или CRM. Кампании, площадки, запросы, суммы и ID сделок вымышлены. Персональных данных в файлах нет.

| Файл | Что имитирует | Что проверяет |
|---|---|---|
| `direct_campaigns_2026-09.csv` | Директ, кампании по дням (Windows-1251, `;`, строка заголовка отчёта, «Итого») | пропуск даты 14.09, НДС, удаление итоговой строки |
| `direct_search_queries_2026-09.xlsx` | Директ, поисковые запросы (XLSX) | чтение XLSX, низкая статистика, нецелевые запросы |
| `direct_placements_2026-09.tsv` | Директ, площадки РСЯ (UTF-8 с BOM, табуляция) | площадки без конверсий, отсутствие периода |
| `metrica_goals_2026-09.csv` | Метрика, две цели по кампаниям, строка «Итого и средние» | запрет суммировать разные цели |
| `crm_leads_2026-09.csv` | CRM, сделки со статусами и utm_campaign | качество лидов, сопоставление utm с кампаниями |
