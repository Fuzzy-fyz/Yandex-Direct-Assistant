# Yandex Direct Assistant

Личный навык Claude для анализа Яндекс Директа, Яндекс Метрики и CRM по выгрузкам CSV и XLSX. Главный принцип — безопасность: навык анализирует данные и предлагает действия, но ничего не меняет в рекламном кабинете без явного подтверждения конкретных нумерованных пунктов.

**Статус: этап 1 — только выгрузки.** Подключения к API нет, токены не нужны и не запрашиваются.

## Что умеет

- Читать и унифицировать выгрузки: кампании, поисковые запросы и площадки Директа, цели Метрики, сделки из CRM.
- Проверять качество данных до оптимизации: пропуски дат, дублирование целей, итоговые строки, НДС, модель атрибуции, неполные отчёты.
- Оценивать результат по бизнес-метрикам — продажам, качественным лидам, CPA, ДРР, ROAS, ROMI. CTR и цена клика нужны только для поиска причин.
- Не делать выводов при недостатке статистики. Для этого навык сравнивает фактические конверсии с ожидаемыми: расход ÷ ориентир CPA.
- Аккуратно предлагать минус-слова: с уровнем исключения и риском потерять полезный трафик.
- Готовить ежедневные и еженедельные отчёты, аварийные сообщения и базовый аудит при первом запуске.

## Правила безопасности

- Режим по умолчанию — только чтение: анализ и рекомендации.
- Подтверждением считается только фраза вида «Подтверждаю 1 и 3». «Давай» или «оптимизируй» навык подтверждением не считает.
- Даже подтверждённые действия проверяются по лимитам в `references/change-limits.md`. Слишком крупные изменения навык разбивает на этапы.
- На этапе 1 изменения вносит сам владелец кабинета по пошаговой инструкции. Исходные показатели фиксируются в журнале изменений.
- Скрипт обработки выгрузок работает локально: сетевые соединения заблокированы, исходные файлы не меняются, столбцы с персональными данными удаляются.

## Быстрый старт

1. Установите навык — см. [INSTALL.md](INSTALL.md).
2. Заполните профиль бизнеса по шаблону `yandex-direct-assistant/references/business-profile.md` и храните его рядом с выгрузками, а не в репозитории.
3. Подключите к задаче в Claude папку с выгрузками и напишите:

   > Первый запуск. В папке выгрузки за сентябрь 2026: кампании Директа, поисковые запросы, площадки РСЯ, цели Метрики и сделки из CRM. Профиль бизнеса лежит там же. Сделай базовый аудит.

Скрипт можно запустить и вручную (Python 3.7+, только стандартная библиотека; для XLSX используется openpyxl, если он установлен):

```bash
python3 yandex-direct-assistant/scripts/normalize_exports.py exports/*.csv exports/*.xlsx --out /tmp/normalized --target-cpa 5000
```

Результат: `summary.md` — итоги, топ объектов, флаги малой статистики, замечания к качеству данных; `summary.json`; нормализованные CSV.

## Проверки

В `yandex-direct-assistant/evals/evals.json` шесть сценариев:

1. Запрос с малой статистикой.
2. Высокий CTR при плохом CPA.
3. Исключение площадки только после подтверждения.
4. Базовый аудит по выгрузкам.
5. Расплывчатое «давай, оптимизируй» при превышении лимита.
6. Токен, присланный в чат.

Тестовые выгрузки в `evals/files/` синтетические.

## Данные и секреты

`.gitignore` исключает `.env`, ключи, выгрузки CSV/XLSX (кроме синтетических тестовых), результаты нормализации, логи, заполненный профиль бизнеса и журнал изменений. Не добавляйте в репозиторий реальные выгрузки, данные CRM и токены.

## Дальше

Подключение API Директа и Метрики — отдельный этап по схеме из `references/api-roadmap.md`. Это три независимых шага: получение статистики (только чтение), подготовка плана изменений и применение только подтверждённых пунктов. Токены хранятся в локальном `.env`, вне Git.
